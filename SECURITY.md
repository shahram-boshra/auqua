# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and select
**Report a vulnerability**
(<https://github.com/shahram-boshra/auqua/security/advisories/new>).
Do not open a public issue for a vulnerability.

An initial response is given within 14 days of the report.

## Supported versions

The project is pre-alpha. Fixes are made on `main` and released as a new
version; earlier versions are not patched.
